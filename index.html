3 Check the envelope

Replays 12 past weeks as if forecasting them, with a model trained only on earlier data, and counts how often actual load landed inside each band. Takes about 30–90 seconds in the browser.

A calibrated envelope lands near 50%, 80% and 95%. Per-day figures rest on fewer hours and bounce more. Forecast temperatures in the replay use the weather error set in step 2.

How it works
  • Engine: the loadforecast Python package (pandas, NumPy, scikit-learn), running in your browser through Pyodide. Same code as the command-line tool and Streamlit app.
  • Forecast model: ridge regression (or gradient boosting) on hour, weekday, US holidays, cooling and heating degrees around an auto-selected balance point, 24h and 72h rolling temperatures, and time-of-day weather interactions.
  • Accuracy: measured on the most recent 15% of history, held out from training. The model is then refit on all history.
  • Envelope: 200 simulated forecasts. Each adds temperature-forecast error that grows with lead time, reruns the model, and adds a day of real out-of-sample model error from a historical day with similar temperatures. Bands are percentiles across the simulations; daily-peak ranges use each simulation's own peak.
